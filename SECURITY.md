# Security policy

The checker is a static page. It has no server side and makes no network
requests, and the only thing it stores is your choice of page theme, kept
in the browser's local storage.

If you find a way for the page to leak data, run injected content, or send
anything off the device, please report it privately through the
repository's private vulnerability reporting under the Security tab. You can
also reach the maintainer through the contact options on
<https://github.com/didvc/>. Please avoid filing a public issue for anything
exploitable.

Only the latest version on the default branch receives fixes.
